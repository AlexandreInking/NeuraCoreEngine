1. Visión General y Filosofía de Arquitectura

Neura-Core v2.0-ULTRA es una plataforma cognitiva desacoplada de alto rendimiento. Abstrae la captura física (mocap facial/corporal y rendering visual) para enfocar recursos en la orquestación afectiva, razonamiento simbólico y memoria jerárquica contextual de alta densidad.

2. Especificaciones de Memoria Jerárquica (TencentDB Model)

Nivel Nombre Descripción Técnica Estrategia de Retención
L0 Raw Conversation & Logs Buffer circular lock-free en Redis Streams (`MAXLEN 200`). Registra audio crudo, prosodia y transcripción. Expira a los 30 min o se condensa en L1 al cerrar sesión.
L1 Atomic Facts Index Índice de vectores (IVF-PQ + HNSW) con metadatos de timestamp, valencia y certeza. Vector search ponderado por decay exponencial de tiempo.
L2 Scenario & Context DAG Grafo de contexto en AST Markdown con abstracción simbólica Mermaid. Estructura persistente en formato relacional estructurado.
L3 Persona & Core Profile Perfil consolidado del agente, moralidad y modelo acumulado. Persistente, inyectado dinámicamente al System Prompt (< 800 tokens).

4. Protobuf Stream Spec (`neuracore_v2.proto`)

syntax = "proto3";
package neuracore.v2;

service NeuraCoreService {
  rpc BiDirectionalStream (stream ClientFrame) returns (stream ServerFrame);
}

message ClientFrame {
  string tenantId = 1;
  string agentId = 2;
  string conversationId = 3;
  int64 timestampMs = 4;
  oneof payload {
    string textContent = 5;
    bytes pcmAudioData = 6;
  }
}

message VadVector {
  float valence = 1;
  float arousal = 2;
  float dominance = 3;
}

message ServerFrame {
  string agentId = 1;
  VadVector vadVector = 2;
  string responseTextChunk = 3;
  string animationTag = 4;
}
