# Neura-Core v0.7 — Beta: LLM Orchestrator & Full Cognitive Loop

> **Objetivo:** El ciclo cognitivo completo funciona de extremo a extremo: input de texto/audio → L0 buffer → EKF VAD → memoria L1/L2/L3 → System Prompt compilado → LLM response streaming → SSML output. El launcher muestra el pipeline completo en una sola pantalla.

---

## Stack Adicional Esta Versión

- **LLM Provider:** OpenAI GPT-4o / Anthropic Claude / Ollama (configurable)
- **Streaming:** Server-Sent Events (SSE) via `reqwest` + `tokio` en Rust
- **Orquestador:** Módulo Rust `CognitiveOrchestrator` que coordina todos los subsistemas
- **UI Nuevo:** Panel "Live Session" — pipeline completo visible en una pantalla con flujo animado

---

## Hito 7.2 — Pipeline End-to-End: Input → L0 → EKF → Memory Query → Prompt

**Entregable usable:** Campo de texto en "Live Session" donde escribir un mensaje activa el pipeline completo y muestra cada paso en tiempo real.

### Sub-metas
- [ ] Input de texto → escritura a L0 (Redis) → extracción VAD (EKF) → query L1 (Qdrant) → query L2 (Neo4j) → compilar System Prompt (PostgreSQL + token budget)
- [ ] Visualizador de pipeline: diagrama de flujo con cada nodo que se ilumina en verde al completarse
- [ ] Tiempo de cada paso mostrado en ms al completarse
- [ ] Nodo que falla se ilumina en rojo con mensaje de error expandible
- [ ] Botón "Reintento" para reejecutar el paso fallido

### ✅ Revisión Manual Requerida
- Enviar el mensaje del mercader ("¡Es un robo!") y verificar que los 5 pasos del pipeline se iluminan en orden en ≤ 200ms total
- Verificar que el System Prompt compilado en el último paso tiene el VAD correcto y los hechos L1 más relevantes
- Desconectar Qdrant, enviar mensaje y verificar que el paso L1 falla en rojo y los demás continúan con advertencia

## Hito 7.4 — VAD Post-Response: Actualización del Estado Emocional

**Entregable usable:** Después de cada respuesta del LLM, el VAD del agente se actualiza y el visualizador 3D lo refleja.

### Sub-metas
- [ ] El LLM incluye en su respuesta un bloque JSON de VAD delta (via function calling / structured output):
  ```json
  { "vad_delta": { "valence": -0.15, "arousal": 0.10, "dominance": 0.05 } }
  ```
- [ ] El orquestador aplica el delta al estado VAD actual con la decay function
- [ ] La esfera 3D se anima suavemente hacia la nueva posición (transición 500ms)
- [ ] Historial de VAD: gráfico de línea temporal de V, A, D para la sesión completa
- [ ] Exportar historial VAD de la sesión como `vad_history_session_ID.json`

### ✅ Revisión Manual Requerida
- Enviar 5 mensajes consecutivos y verificar que el gráfico temporal de VAD muestra cambios coherentes
- Verificar que tras un mensaje de disculpa del usuario, la valence del agente sube (respuesta empática)
- Exportar el historial y verificar que el JSON contiene una entrada por cada turno de conversación
