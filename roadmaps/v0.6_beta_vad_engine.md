# Neura-Core v0.6 — Beta: VAD Affect Engine Core

> **Objetivo:** El motor afectivo VAD funciona en tiempo real. El launcher muestra el estado emocional del agente visualmente (gauge 3D, hex color, aura animada), responde a estímulos de texto/audio simulados y emite configuraciones SSML correctas.

---

## Stack Adicional Esta Versión

- **VAD Engine:** Implementación Rust pura (sin dependencias externas) con EKF integrado
- **Visualización 3D VAD:** Three.js o React Three Fiber embebido en el launcher
- **Audio Analysis:** `web-audio-api` en el frontend para captura de micrófono
- **SSML Builder:** Módulo Rust que genera XML SSML desde el estado VAD
- **UI Nuevo:** Panel "Affect Engine" con visualizador VAD 3D, controles de simulación y output SSML

---

## Hito 6.1 — Core Loop VAD en Rust: Integración y Decaimiento

**Entregable usable:** Panel "Affect Engine > Simulator" con sliders de estímulo que actualizan el VAD en tiempo real.

### Sub-metas
- [ ] Struct `VadState` con `valence`, `arousal`, `dominance`: todos `f32 ∈ [-1.0, 1.0]`
- [ ] Función `vadStep(current, baseline, stimulus, gamma, dt) -> VadState` implementada en Rust
- [ ] Ruido estocástico Gaussiano `η(t)` con intensidad configurable
- [ ] Panel Simulator: 3 sliders de estímulo (∆V, ∆A, ∆D) + slider gamma + botón "Tick Manual"
- [ ] VAD actual mostrado numéricamente actualizado en cada tick
- [ ] Modo "Auto-tick": ejecuta un tick cada 500ms con estímulo cero (solo decaimiento)

### ✅ Revisión Manual Requerida

- Aplicar estímulo ∆V=+1.0 en un tick y verificar que valence no supera +1.0 (clamp activo)
- Cambiar gamma=0.99 y verificar que el decaimiento es extremadamente lento (inercia alta)

## Hito 6.3 — Análisis de Prosodia de Audio en Vivo

**Entregable usable:** Botón "Usar Micrófono" captura voz en tiempo real y extrae pitch, energía y cadencia para calcular ∆E.

### Sub-metas
- [ ] Acceso al micrófono mediante Web Audio API dentro del WebView interno de Tauri
- [ ] Análisis FFT en tiempo real: frecuencia fundamental (pitch Hz) con `pitchfinder.js`
- [ ] RMS para energía en dB
- [ ] Detección de cadencia (sílabas/seg) con zero-crossing rate
- [ ] Mapeo de métricas a ∆VAD stimulus:
  ```
  pitch_norm = (pitchHz - 100) / 300   → influye en ∆A y ∆V
  energy_norm = (energyDb + 30) / 30   → influye en ∆A
  rate_norm = rate / 10                → influye en ∆D
  ```
- [ ] Visualizador de ondas de audio junto al gauge 3D

### ✅ Revisión Manual Requerida
- Hablar con voz calmada (baja energía, pitch bajo) y verificar que el VAD permanece cerca del baseline
- Hablar con voz elevada y agitada (pitch alto, alta energía) y verificar que arousal sube > +0.5
- Verificar que el micrófono se desactiva completamente al hacer clic en "Detener" (indicador visual)

## Hito 6.5 — EKF: Fusión de Prosodia + Léxico
