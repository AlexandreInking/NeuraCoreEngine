# Neura-Core v0.5 — Alpha: L3 Persona Compiler & System Prompt Engine

> **Objetivo:** El sistema puede definir, almacenar y compilar perfiles de agente completos (L3) en un System Prompt optimizado con ventana rígida de ≤ 800 tokens. El launcher permite editar el perfil y previsualizar el prompt resultante antes de enviarlo al LLM.

---

## Stack Adicional Esta Versión

- **Storage L3:** PostgreSQL 16 en Docker + `sqlx` Rust driver (async)
- **Token Counter:** `tiktoken-rs` para conteo preciso de tokens
- **LLM Preview:** Llamada real al LLM configurado con el System Prompt compilado
- **UI Nuevo:** Panel "Memory > L3 Persona" con editor de perfil y previewer de prompt

## Hito 5.3 — Compilador de System Prompt con Budget de Tokens

**Entregable usable:** Panel "Compilar Prompt" que muestra el System Prompt final con conteo de tokens en tiempo real.

### Sub-metas
- [ ] Función Rust `compileSystemPrompt(agentId, vadState, activeL2NodeId, topL1Facts) -> String`
- [ ] Estructura del prompt compilado:
  ```
  [PERFIL BASE L3: ~250-450 tokens]
  [VAD ACTUAL + COLOR HEX: ~50 tokens]
  [ESCENARIO L2 ACTIVO: ~100-200 tokens]
  [TOP-3 HECHOS L1: ~80-150 tokens]
  TOTAL: debe ser ≤ 800 tokens
  ```
- [ ] Barra de progreso de tokens en la UI: verde < 600, amarillo 600-750, rojo > 750
- [ ] Si el compilado supera 800 tokens → recorta automáticamente L1 facts de menor score
- [ ] Preview del prompt en el launcher con syntax highlighting de cada sección
