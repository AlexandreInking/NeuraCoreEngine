# Neura-Core v0.8 — Beta: Output Engine, SSML & Client SDKs

> **Objetivo:** El motor de salida produce payloads estructurados completos (JSON, Protobuf, SSML) que son consumibles por clientes reales. Se incluyen SDKs básicos para Unity (C#) y Unreal Engine 5 (C++) con ejemplos ejecutables.

---

## Stack Adicional Esta Versión

- **gRPC Server:** Tonic (Rust) con `neuracore_v2.proto` compilado
- **WebSocket Server:** Axum + `tokio-tungstenite`
- **Unity SDK:** Package C# con `NeuraCoreClient.cs`
- **UE5 Plugin:** Plugin C++ con `UNeuraCoreSubsystem`
- **SSML Preview:** ElevenLabs API o Azure TTS para síntesis real de audio
- **UI Nuevo:** Panel "Output Engine" con monitor de payload en vivo + test de clientes

---

## Hito 8.1 — Serialización JSON Completa del Payload de Salida

**Entregable usable:** Panel "Output Engine" muestra el payload JSON completo generado en tiempo real para cada turno.

### Sub-metas
- [ ] Struct Rust `NeuraCoreOutputPayload` que mapea exactamente al schema JSON de producción
- [ ] Serialización con `serde_json` incluyendo todos los campos: `affectState`, `memoryTrace`, `cognitiveOutput`, `behavioralTriggers`
- [ ] Panel "Output Engine": visor JSON con syntax highlighting y collapse de secciones
- [ ] Botón "Copiar JSON" al clipboard
- [ ] Botón "Validar Schema" que verifica el payload contra el JSON Schema draft-07
- [ ] Indicador de tamaño del payload en bytes

### ✅ Revisión Manual Requerida
- Enviar el mensaje del mercader y verificar que el payload contiene todos los campos del schema
- Hacer clic en "Validar Schema" y verificar que retorna "✅ Válido" sin errores
- Verificar que `behavioralTriggers.animationTag` corresponde correctamente al cuadrante VAD calculado

- [ ] Botón "Iniciar servidor gRPC" / "Detener servidor gRPC" con indicador de estado
- [ ] Test client integrado en el launcher: enviar un `ClientFrame` de prueba y ver el `ServerFrame` de respuesta
- [ ] Mostrar número de conexiones activas en tiempo real

### ✅ Revisión Manual Requerida

- Detener el servidor y verificar que las conexiones se cierran graciosamente (no hard crash)

## Hito 8.4 — SDK Unity (C#): Plugin de Integración Básica

**Entregable usable:** Unity Package importable que conecta un NPC a Neura-Core con 10 líneas de C#.

### Sub-metas
- [ ] `NeuraCoreClient.cs`: WebSocket client con reconexión automática
- [ ] `NeuraCorePayload.cs`: clases C# que deserializan el JSON de salida
- [ ] `NeuraCoreAnimatorBridge.cs`: aplica `animationTag` al `Animator` de Unity via `SetTrigger()`
- [ ] `NeuraCoreUIBridge.cs`: aplica `uiHexColor` a un `Image` component
- [ ] Escena de ejemplo: cubo con material que cambia de color según el VAD
- [ ] `README_Unity.md` con instrucciones de importación en 5 pasos

### ✅ Revisión Manual Requerida
- Importar el package en un proyecto Unity vacío y verificar que compila sin errores
- Ejecutar la escena de ejemplo con Neura-Core activo; verificar que el cubo cambia de color en cada turno
- Desconectar el servidor a mitad de sesión; verificar que Unity no crashea y muestra mensaje de reconexión

## Hito 8.5 — Plugin Unreal Engine 5 (C++): Subsystem de Integración

**Entregable usable:** Plugin UE5 instalable que conecta un Blueprint NPC al motor cognitivo via Delegate.

### Sub-metas
- [ ] `UNeuraCoreSubsystem.h/.cpp`: `GameInstanceSubsystem` con conexión gRPC/WebSocket
- [ ] `FNeuraCorePayload`: struct UE5 con todos los campos del payload
- [ ] `FOnAffectStateUpdated`: Delegate multicast que Blueprint puede bindear
- [ ] Nodo Blueprint "Send User Input" expuesto para diseñadores sin código
- [ ] `NeuraCoreAnimMapper.cpp`: mapea `animationTag` a AnimMontage de UE5
- [ ] README de instalación del plugin y configuración de Build.cs

### ✅ Revisión Manual Requerida
- Agregar el plugin a un proyecto UE5 vacío y verificar que compila sin errores en Rider/VS
- Desde un Blueprint, conectar el Delegate y verificar que la variable `AnimTag` se actualiza en cada respuesta
- Verificar que el `animationTag` "GESTURE_POINT_FINGER_ANGRY" dispara el AnimMontage correcto en el NPC

## Criterio de Aceptación de la Versión 0.8

| Check | Criterio |
| :--- | :--- |
| JSON Payload | Válido contra JSON Schema draft-07, todos los campos presentes |
| gRPC Server | Bi-directional stream funcional con múltiples conexiones simultáneas |
| WebSocket/SSE | Latencia payload ≤ 100ms desde generación hasta cliente web |
| Unity SDK | Importable, compila, cambia color del NPC correctamente |
| UE5 Plugin | Compila, Delegate funcional, AnimTag aplicado correctamente |
