# Neura-Core v0.3 — Alpha: L1 Atomic Facts Index (Vector Search)

> **Objetivo:** El sistema extrae hechos atómicos de las entradas L0 y los indexa como vectores consultables. El launcher visualiza los hechos recuperados y permite hacer búsquedas semánticas manuales.

---

## Stack Adicional Esta Versión

- **Vector DB:** Qdrant v1.9+ en Docker
- **Embeddings:** OpenAI `text-embedding-3-small` (o local via Ollama `nomic-embed-text`)
- **Cliente Qdrant Rust:** `qdrant-client`
- **Extractor de Hechos:** LLM call con prompt de extracción a tripletas SPO
- **UI Nuevo:** Panel "Memory > L1 Atomic Facts" en el launcher
