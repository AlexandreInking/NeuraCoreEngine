# Neura-Core v0.1 — Alpha: Foundation & Desktop Launcher

> **Objetivo:** entregar desde el día 1 una aplicación de escritorio descargable. El launcher Tauri es el producto central de todas las versiones siguientes; React se ejecuta únicamente dentro de la ventana nativa. Cada hito termina con algo que se puede abrir, ver o interactuar sin publicar una webapp.

---

## Stack Tecnológico Base

- **Aplicación de escritorio:** Tauri v2
- **UI embebida:** React 18 + TypeScript + Vite
- **Núcleo nativo:** Rust mediante comandos y eventos Tauri
- **Empaquetado:** bundles nativos de Tauri para el sistema operativo objetivo
- **Build/CI:** GitHub Actions + cargo build

Los protocolos HTTP, WebSocket, SSE o gRPC que aparezcan en hitos posteriores son interfaces de integración del motor; no convierten el producto principal en una webapp.

## Hito 1.7 — Motor Cognitivo Local (Personalidad, Emociones y Memoria)

**Entregable usable:** el launcher ejecuta un motor cognitivo local que simula personalidad dual consciente/subconsciente (HEXACO), estados emocionales (Plutchik + VAD), moralidad, introspección y memoria jerárquica con olvido (Ebbinghaus), represión (Freud) y consolidación onírica. El chat responde en carácter usando este estado y el modelo DeepSeek configurado.

> Guía de diseño: documento "NetNavi Superinteligente" (personalidad dual, rueda de Plutchik, curva de olvido, represión, sueños, introspección). Implementación local-first en TypeScript: sin PostgreSQL/Redis/Docker, el estado persiste en `localStorage` del launcher.

### Sub-metas

- [x] Modelo de datos cognitivo: HEXACO consciente/subconsciente, alineamiento moral dual, emociones Plutchik + VAD, memoria, introspección
- [x] Motor de análisis de mensajes con DeepSeek (JSON estructurado) y fallback heurístico determinista
- [x] Motor emocional: transición VAD con inercia γ según la especificación (`E(t+Δt) = baseline + (E−baseline)·e^(−γ·Δt) + ΔE`)
- [x] Motor de personalidad: evolución por interacción (Bandura) con límite de deriva ≤ 5 puntos/día y conflicto consciente/subconsciente
- [x] Motor de memoria: curva de olvido de Ebbinghaus, represión freudiana, memoria de trabajo (7±2), recuperación con relevancia psicológica
- [x] Ciclo de sueño: consolidación de memorias, resolución de conflictos e insights espontáneos (auto tras 2h y manual en Memory)
- [x] Introspección: autoconciencia, estado de ánimo y resumen del mundo interior
- [x] System Prompt compilado con personalidad, moral, emociones, introspección y memorias relevantes para respuestas en carácter
- [x] Panel cognitivo con datos reales: 5 métricas, HEXACO dual, VAD, Plutchik y capas L0–L3
- [x] Página Memory: unidades de memoria con fuerza, reprimidas, ciclos de sueño y botón "Dream cycle"
- [x] Modelo por defecto: `deepseek-v4-flash-0731`

### ✅ Revisión Manual Requerida

- Enviar un mensaje negativo intenso y verificar que la emoción dominante y el VAD cambian; reiniciar y confirmar persistencia.
- Enviar el mismo mensaje dos veces y verificar que la memoria relevante aparece en la recuperación (System Prompt / panel).
- Usar "Dream cycle" en Memory y verificar que aparecen insights y consolidación.

## Hito 1.8 — Psicología Profunda: Jung, Psicodinámica y Alineación Corazón-Mente

**Entregable usable:** el sistema psicológico del documento NetNavi se refleja en todas las pestañas: arquetipos jungianos, sombra, mecanismos de defensa, jerarquía de Maslow, apego, marcadores somáticos (Damasio), emociones de Ekman, contagio emocional, inteligencia emocional (Goleman) y alineación corazón-mente (Kahneman/Haidt). El agente de chat incorpora todo esto a su System Prompt para representar su rol con naturalidad.

### Sub-metas

- [x] Modelo jungiano: persona, sombra, anima/animus, self y arquetipo activo con evolución gradual
- [x] Perfil de sombra (agresión, miedo, deseo, rebeldía) que crece con experiencias negativas e intensas
- [x] Mecanismos de defensa (Freud): represión, proyección, desplazamiento, sublimación, racionalización, negación + mecanismo activo
- [x] Jerarquía de necesidades (Maslow) con foco actual y estilo de apego (Ainsworth) derivado del balance de confianza
- [x] Marcadores somáticos (Damasio): creación por alto impacto emocional, refuerzo por repetición, influencia en decisiones
- [x] Emociones de Ekman derivadas de Plutchik + inteligencia emocional (Goleman) y contagio emocional (Hatfield)
- [x] Motor de decisiones corazón-mente: propuesta lógica vs. emocional, coherencia, sistema dominante y estrategia de resolución
- [x] Historial emocional (últimas 48 muestras) persistido con el estado
- [x] Migración de estado v1 → v2 conservando datos existentes
- [x] System Prompt ampliado: arquetipos, sombra, psicodinámica, necesidades, marcadores somáticos y corazón-mente
- [x] Página Affect Engine: aura emocional, VAD, rueda de Plutchik, Ekman, EI, marcadores somáticos, historial y simulador de estímulos
- [x] Dashboard con snapshot cognitivo (emoción dominante, consciencia, memorias, conflicto) y página Memory con memoria de trabajo y reprimidas
