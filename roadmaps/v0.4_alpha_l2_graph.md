# Neura-Core v0.4 — Alpha: L2 Scenario Graph & Mermaid Canvas

> **Objetivo:** El sistema agrupa hechos L1 en nodos situacionales (L2), los representa como grafos Mermaid interactivos en el launcher y permite inspeccionar, editar y ejecutar drill-down sobre ellos.

> **⚠ Adaptación (hito 4.1–4.5):** el grafo de escenarios vive en `apps/launcher/src/l2/` con un seam `L2Store` (semántica Neo4j) y una implementación local (`LocalL2Store`, localStorage). El clustering (hito 4.2) es semántico real: re-embebe los hechos L1 (certeza ≥ 75%) con `all-MiniLM-L6-v2` y agrupa por similitud de coseno o entidades compartidas; los grupos de 3+ hechos crean nodos con nombre generado por LLM (DeepSeek) y fallback heurístico. El canvas Mermaid (hito 4.3) se renderiza en un SVG propio interactivo (pan/zoom, click para detalle, doble click para editar label, export PNG) y el string Mermaid subyacente se muestra, copia y descarga. El Tool Call Simulator (hito 4.4) comprime secuencias JSON a Mermaid con ahorro de tokens y colores por HTTP (2xx/4xx/5xx). El drill-down (hito 4.5) recupera el entry L0 exacto y advierte si expiró (TTL 24h). Un futuro adaptador Neo4j puede implementar el mismo seam vía su API HTTP.

- **Graph Store:** Neo4j Community en Docker → **adaptado:** `LocalL2Store` en TS (`src/l2/store.ts`, seam `L2Store`)
- **Cliente Neo4j Rust:** `neo4rs` → no aplica (adaptador TS vía seam)
- **Markdown AST:** `pulldown-cmark` → no aplica (clustering semántico con embeddings)
- **Mermaid Render en UI:** `mermaid.js` → **adaptado:** canvas SVG propio (`L2Canvas` en `src/L2Panel.tsx`) + string Mermaid exportable/copiable
- **UI Nuevo:** Panel "Memory > L2 Scenarios" (`src/L2Panel.tsx`)

## Hito 4.2 — Creación de Nodos L2 por Clustering Semántico

**Entregable usable:** Botón "Analizar L1 → Crear Nodos L2" que genera escenarios automáticamente desde hechos.

### Sub-metas
- [x] Algoritmo de clustering: agrupar hechos L1 con `certaintyScore >= 0.75` que compartan entidades en común
- [x] Si 3+ hechos comparten contexto → crear nodo L2 con nombre generado por LLM
- [x] Estructura del nodo L2 en Neo4j:
  ```cypher
  CREATE (s:ScenarioNode {
    nodeId: "SCENARIO_MERCHANT_PRICE_01",
    parentScenario: "ROOT_GAMING_NPC",
    status: "ACTIVE",
    linkedFactIds: ["fact_uuid_01","fact_uuid_02","fact_uuid_03"],
    createdAt: timestamp()
  })
  ```
- [x] Panel L2: lista de nodos con estado (ACTIVE / CLOSED / ESCALATED), número de hechos vinculados
- [x] Botón "Crear nodo manual" con formulario

### ✅ Revisión Manual Requerida
- Indexar 5 hechos relacionados con "reembolso" y ejecutar análisis; verificar que se crea un nodo L2
- Crear un nodo manualmente con 3 hechos y verificar que aparece en Neo4j Browser
- Verificar en Neo4j Browser con `MATCH (s:ScenarioNode) RETURN s` que los nodos tienen todos los campos
