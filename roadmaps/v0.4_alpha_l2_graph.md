# Neura-Core v0.4 — Alpha: L2 Scenario Graph & Mermaid Canvas

> **Objetivo:** El sistema agrupa hechos L1 en nodos situacionales (L2), los representa como grafos Mermaid interactivos en el launcher y permite inspeccionar, editar y ejecutar drill-down sobre ellos.

---

## Stack Adicional Esta Versión

- **Graph Store:** Neo4j Community en Docker (puerto 7474 HTTP, 7687 Bolt)
- **Cliente Neo4j Rust:** `neo4rs`
- **Markdown AST:** `pulldown-cmark` para parseo y generación de nodos L2
- **Mermaid Render en UI:** `mermaid.js` embebido en el WebView interno de Tauri
- **UI Nuevo:** Panel "Memory > L2 Scenarios" con canvas Mermaid interactivo

---

## Hito 4.1 — Infraestructura Neo4j Local

**Entregable usable:** Neo4j corriendo, el launcher muestra estado de conexión y lista de nodos existentes.

### Sub-metas
- [ ] Agregar Neo4j al `docker-compose.yml` con credenciales en `.env`
- [ ] Indicador de conexión Neo4j en el launcher (tercer indicador junto a Redis y Qdrant)
- [ ] Panel L2: lista de nodos escenario existentes (vacía inicialmente)
- [ ] Panel Settings: configurar Bolt URI, usuario, password
- [ ] Query de prueba: `MATCH (n) RETURN count(n)` y mostrar resultado en launcher

### ✅ Revisión Manual Requerida
- Abrir Neo4j Browser en `http://localhost:7474` y confirmar conexión con las credenciales del `.env`
- Ejecutar la query de prueba desde el launcher y verificar que retorna `0` (base vacía)
- Detener Neo4j y confirmar que el indicador del launcher cambia a rojo

## Hito 4.2 — Creación de Nodos L2 por Clustering Semántico

**Entregable usable:** Botón "Analizar L1 → Crear Nodos L2" que genera escenarios automáticamente desde hechos.

### Sub-metas
- [ ] Algoritmo de clustering: agrupar hechos L1 con `certaintyScore >= 0.75` que compartan entidades en común
- [ ] Si 3+ hechos comparten contexto → crear nodo L2 con nombre generado por LLM
- [ ] Estructura del nodo L2 en Neo4j:
  ```cypher
  CREATE (s:ScenarioNode {
    nodeId: "SCENARIO_MERCHANT_PRICE_01",
    parentScenario: "ROOT_GAMING_NPC",
    status: "ACTIVE",
    linkedFactIds: ["fact_uuid_01","fact_uuid_02","fact_uuid_03"],
    createdAt: timestamp()
  })
  ```
- [ ] Panel L2: lista de nodos con estado (ACTIVE / CLOSED / ESCALATED), número de hechos vinculados
- [ ] Botón "Crear nodo manual" con formulario

### ✅ Revisión Manual Requerida
- Indexar 5 hechos relacionados con "reembolso" y ejecutar análisis; verificar que se crea un nodo L2
- Crear un nodo manualmente con 3 hechos y verificar que aparece en Neo4j Browser
- Verificar en Neo4j Browser con `MATCH (s:ScenarioNode) RETURN s` que los nodos tienen todos los campos

## Hito 4.3 — Visualización Mermaid Interactiva del Grafo

**Entregable usable:** Grafo Mermaid renderizado en el launcher, clickeable por nodos.

### Sub-metas
- [ ] Componente React `<MermaidCanvas>` renderiza diagrama desde string Mermaid
- [ ] Generación automática del string Mermaid desde nodos Neo4j:
  ```mermaid
  graph TD
    ROOT[ROOT_GAMING_NPC] --> S1[MERCHANT_PRICE_01: ACTIVE]
    S1 --> F1[fact: user_robó_manzana]
    S1 --> F2[fact: precio_subió_por_dragón]
  ```
- [ ] Click en nodo muestra panel lateral con detalles: hechos vinculados, timestamps, status
- [ ] Zoom in/out y pan del canvas con rueda del mouse
- [ ] Botón "Exportar como PNG" del canvas actual

### ✅ Revisión Manual Requerida
- Crear 3 nodos L2 y verificar que el grafo Mermaid los muestra correctamente conectados
- Hacer clic en un nodo y verificar que el panel lateral muestra los hechos L1 vinculados
- Exportar el canvas como PNG y verificar que la imagen es legible

## Hito 4.4 — Compresión Mermaid de Tool Calls (Simbólica)

**Entregable usable:** Editor de "Tool Call Simulator" que comprime secuencias en Mermaid automáticamente.

### Sub-metas
- [ ] Panel "Mermaid Canvas Simulator": lista de tool calls simuladas (formulario con nombre, resultado, status HTTP)
- [ ] Botón "Comprimir a Mermaid" genera el grafo simbólico desde la secuencia
- [ ] Ahorro de tokens estimado mostrado: "Reducción: 4,200 → 180 tokens (95.7%)"
- [ ] Nodos con HTTP 2xx en verde, 4xx en amarillo, 5xx en rojo
- [ ] Canvas editable: doble click en nodo para editar su label

### ✅ Revisión Manual Requerida
- Agregar 5 tool calls simuladas y comprimir; verificar que el grafo tiene 5 nodos
- Cambiar un resultado a HTTP 500 y verificar que el nodo cambia a color rojo
- Editar el label de un nodo y verificar que el string Mermaid subyacente se actualiza

## Hito 4.5 — Drill-Down Query: Nodo L2 → Log L0 Exacto

**Entregable usable:** Click en nodo fallido del grafo → abre el log L0 exacto de esa llamada.

### Sub-metas
- [ ] Cada nodo Mermaid tiene un `l0EntryId` vinculado al crear la herramienta
- [ ] Click derecho en nodo → menú contextual "Drill-Down: Ver Log Raw"
- [ ] Abre modal con el entry L0 completo de Redis para ese `entryId`
- [ ] Si el entry ya expiró en Redis, muestra advertencia y el último snapshot disponible
- [ ] Botón "Reintentar Tool Call" (simulado) que regenera el nodo con nuevo resultado

### ✅ Revisión Manual Requerida
- Crear un nodo vinculado a un entry L0 específico; hacer drill-down y verificar que muestra el entry correcto
- Expirar manualmente el entry en Redis (`DEL key`) y verificar que la advertencia aparece
- Hacer drill-down en un nodo sin `l0EntryId` y verificar que el error se maneja gracefully
