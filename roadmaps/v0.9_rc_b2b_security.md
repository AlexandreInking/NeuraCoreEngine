# Neura-Core v0.9 — RC: B2B APIs, Seguridad & Multi-Tenancy

> **Objetivo:** El sistema está listo para ser ofrecido como servicio B2B. Incluye aislamiento multi-tenant real, autenticación JWT, sanitización PII, dashboard de administración de clientes y pruebas de carga que validan los SLAs de producción.

---

## Stack Adicional Esta Versión

- **Auth:** JWT + `jsonwebtoken` Rust crate / Keycloak opcional para SSO
- **PII Scrubbing:** Regex engine `fancy-regex` + modelo NER ligero (ONNX)
- **Rate Limiting:** `governor` Rust crate (token bucket per tenant)
- **Observabilidad:** Prometheus metrics + Grafana dashboard (Docker)
- **Load Testing:** `k6` scripts para validar SLAs
- **UI Nuevo:** Panel "Admin > Tenants" + Panel "Security" + Panel "Observabilidad"

## Hito 9.3 — Pipeline PII Scrubbing en L0 → L1

**Entregable usable:** Panel "Security > PII Tester" donde ingresar texto con datos sensibles y ver el resultado sanitizado.

### Sub-metas
- [ ] Patrones Regex para: tarjetas de crédito, DNI/CURP/RFC, emails, teléfonos, IBAN
- [ ] Modelo NER ONNX ligero para: nombres propios, direcciones, fechas de nacimiento
