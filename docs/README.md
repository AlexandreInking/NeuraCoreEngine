# Documentación

Neura-Core se distribuye como aplicación de escritorio descargable mediante Tauri. La UI React está embebida en la ventana nativa; este repositorio no define una webapp desplegable.

- Especificaciones técnicas: archivos `NeuraCore_*` en la raíz.
- Planes de versión e hitos: `../roadmaps`.
- Instrucciones de desarrollo y empaquetado: `../README.md`.
